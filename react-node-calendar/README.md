# React + Node Calendar Test

A simple calendar application for testing in a collaborative Git repository.

## Stack
- React + Vite
- Node.js + Express
- REST API for calendar events

## Run

From the project root:

```bash
npm install
npm run install-all
npm run dev
```

Frontend: http://localhost:5173
Backend: http://localhost:5000

## Git test workflow

```bash
git checkout -b calendar-test
git add .
git commit -m "Add React Node calendar test app"
git push -u origin calendar-test
```
