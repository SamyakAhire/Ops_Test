# Library Management System - Java

A substantial single-file Java console application created for Git collaboration/testing.

## Features

- Add, list, search and remove books
- Add, list and remove members
- Issue and return books
- Automatic 14-day loan period
- Overdue detection
- Fine calculation
- Active loan tracking
- Member loan history
- Most borrowed books report
- Category statistics
- Sample data
- Input validation

## Requirements

Java 17 or newer is recommended.

## Run

From the project directory:

```bash
javac src/LibraryManagementSystem.java -d out
java -cp out LibraryManagementSystem
```

## Git test

Add this project to your existing repository:

```bash
git add library-management-java/
git commit -m "Add Java library management test project"
git push origin main
```
